# Purple Hackers

A community platform for ethical hackers, security researchers, and tech enthusiasts.

## Tech Stack
- Next.js 15 (App Router)
- Prisma ORM
- Supabase PostgreSQL (eu-west-1 pooler)
- NextAuth.js (Credentials provider)
- TailwindCSS
- Vercel (deployment)

## Features
- Forum with categories, posts, comments, upvotes, and media uploads
- Real-time chat rooms
- Personal DMs (direct messages)
- Notifications system
- User profiles with avatars, reputation, and badges
- Admin panel (user management, bans, reports)
- Settings page with avatar upload
- Responsive design with purple cyber-aesthetic theme

## Live Demo
https://purple-hackers.vercel.app

## Setup
1. Clone the repo
2. `npm install`
3. Set up environment variables (see `.env.example`)
4. `npx prisma generate`
5. `npm run dev`
